# Reference captures

Unmodified copies of the community IR captures the Emberlink code table was built from,
kept here so the provenance of every byte is checkable without a network round trip.

Source: https://github.com/Lucaslhm/Flipper-IRDB

- `FireTV_Omni_Series_4K.ir` — Amazon Omni / 4-Series
- `toshiba_firetv_v2.ir` — Toshiba Fire TV Edition
- `Insignia_NS_RCFNA_21.ir` — Insignia Fire TV Edition remote

All three agree on NECext address `02 7D` and on every overlapping command byte.
